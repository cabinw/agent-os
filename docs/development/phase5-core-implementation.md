# Agent OS Phase 5: Core Implementation

## Goal

Build the first runnable Agent OS runtime loop.

The objective is not UI first. The objective is to establish the core lifecycle:

User Goal → Supervisor Agent → MCP Server → Agent Execution → Event Update → Project Pulse

## Implementation Order

1. Event Core
2. Agent Registry
3. Task Engine
4. MCP Server
5. Agent SDK
6. Memory Core
7. End-to-end demo

## First Supported Agents

- Supervisor Agent
- Codex Adapter
- Claude Adapter

## Success Criteria

A simple task can be created, assigned, executed, reported and summarized through Agent OS.
