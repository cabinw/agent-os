# Agent OS Project Memory Architecture

## Goal

Preserve long-term project continuity.

## Memory Layers

Raw Events

↓

AI Summary

↓

Knowledge Items

↓

Project Memory

## Stored Information

- decisions
- research
- technical choices
- completed tasks
- agent discussions
- project milestones

## Benefits

A user can return to an old project and quickly understand:

- what happened
- why decisions were made
- current state
- recommended next steps
