# Agent OS MCP Tools v0.1

## Core Tools

### register_agent

Register an agent into Agent OS.

### create_task

Create a new task.

### assign_task

Assign work to an agent.

### send_message

Send instructions, questions, or feedback.

### progress_update

Report current execution progress.

### report_result

Return completed work.

### notify_blocked

Report blockers requiring attention.

## Goal

Create a provider-independent agent collaboration layer.
