# Agent OS MCP API v0.1

## Purpose

MCP provides the communication layer between Agent OS and external agents.

## Core APIs

### register_agent
Register an agent.

### create_task
Create a task.

### assign_task
Assign work to another agent.

### send_message
Send instructions, questions and reports.

### progress_update
Update execution progress.

### report_result
Return completed work.

### notify_blocked
Report blockers requiring attention.
